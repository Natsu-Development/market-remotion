# Nguồn

`SKILL.md` và `LICENSE` chép nguyên từ https://github.com/blader/humanizer (MIT, Siqi Chen), phiên bản 3.1.0,
lấy ngày 2026-09-30 theo yêu cầu người dùng ("install this git to this repo to Humanizer text-gen from AI").
Cài theo cách README của họ cho phép: chép `SKILL.md` vào thư mục skill của repo. Skill trả lời lệnh `/humanizer`.

Cập nhật: `git clone --depth 1 https://github.com/blader/humanizer` rồi chép lại hai file trên.

Dùng trong repo này (xem CLAUDE.md, "Lời đọc do MỘT agent viết"): sau khi người viết trả `_script.md`, soi
bằng các mẫu của humanizer không phụ thuộc ngôn ngữ — "không X mà là Y", câu chốt một dòng, bộ ba ép, mở màn
dàn dựng ("Nói thẳng nhé"), phủ định không ai nói ("Mình không bảo là…"), gạch ngang tràn lan, chữ khoa trương.
Số liệu, thuật ngữ nghề và khuôn câu người dùng đã chốt giữ nguyên.
